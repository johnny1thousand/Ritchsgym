Ritch's Gym homepage

Upload everything in this folder to the web root of the domain, keeping the folder structure:

  index.html      the page
  css/style.css   animations and base styles
  js/main.js      the count-up on the stats band
  images/         all photos and the logo
  video/          add the header video here as hero.mp4

Notes
- Header video: save your clip as video/hero.mp4. It plays muted on a loop. Without it the rower photo shows.
- Fonts (Barlow and Barlow Condensed) load from Google Fonts, so the page needs an internet connection to show them.
- The accent teal is set once near the top of index.html: --accent: #3C879A
- Sign-up buttons go to ClubReady. Other links (training, barber shop, pricing, contact, FAQ, partners) point to the pages on ritchsgym.com.
